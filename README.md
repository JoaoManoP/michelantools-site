# MichelanTools — site

Site do MichelanTools, suíte criativa gratuita para Windows: vídeo e motion graphics, imagem, áudio e 3D.

- Site: https://joaomanop.github.io/michelantools-site/
- Downloads: veja as [releases](https://github.com/JoaoManoP/michelantools-site/releases).

O MichelanTools inclui o FFmpeg (GPL v3). Código-fonte correspondente: https://ffmpeg.org/releases/ffmpeg-6.1.1.tar.xz
